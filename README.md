# Auréa — landing page de estética facial

Landing page demonstrativa premium para uma marca fictícia de medicina estética facial, com direção editorial, narrativa de conversão e motion coordenado.

**Demonstração:** [aurea-estetica-premium-leticia.netlify.app](https://aurea-estetica-premium-leticia.netlify.app)

## Direção do projeto

- Identidade original inspirada no clima sofisticado de clínicas contemporâneas, sem copiar marcas ou layouts existentes.
- CTA único: **Agendar avaliação**.
- Copy responsável, sem depoimentos, métricas, certificações ou resultados inventados.
- Abertura com monograma, hero fotográfico original, manifesto cinético, cards editoriais e desenho facial animado.
- Formulário preparado para captura real pelo Netlify Forms.
- Experiência responsiva, navegável por teclado e compatível com `prefers-reduced-motion`.

## Stack

- React + TypeScript + Vite
- GSAP + ScrollTrigger
- CSS responsivo autoral
- Netlify Forms e Netlify Deploy

## Desenvolvimento local

```bash
npm install
npm run dev
```

Validação de produção:

```bash
npm run build
npm run lint
```
